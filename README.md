# BÀI TẬP XOÁ CƠ SỞ DỮ LIỆU MYSQL

## 1. Xoá Cơ sở dữ liệu bằng giao diện (GUI)
- Bước 1: Mở phần mềm MySQL Workbench và nhìn vào cột SCHEMAS phía bên trái.
- Bước 2: Nhấp chuột phải (Right-click) vào tên Cơ sở dữ liệu cần xoá (ví dụ: `my_database`).
- Bước 3: Nhấp chọn dòng `Drop Schema...` từ danh sách menu ngữ cảnh.
- Bước 4: Hộp thoại xác nhận hiện ra, nhấn chọn `Drop Now` để hoàn tất xoá CSDL.
